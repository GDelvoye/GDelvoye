# Gauthier Delvoye

I build practical web applications and data tools with Python, Django, PostgreSQL, Docker, and JavaScript.

My current focus is turning domain-specific problems into usable applications: card data analysis, probability tools, experiment workflows, and self-hosted services.

## Featured Projects

- [Cube MTG Analyzer](https://github.com/GDelvoye/cube-descriptor): deployed Django/PostgreSQL application for building Magic: The Gathering cubes and analyzing booster probabilities. Live at [cube.gdelvoye.fr](https://cube.gdelvoye.fr/).
- [Napoleon 1806 Combat Assistant](https://github.com/GDelvoye/napoleon1806): static web app that computes board game combat outcome probabilities. Live at [gdelvoye.github.io/napoleon1806](https://gdelvoye.github.io/napoleon1806/).
- [XP Staircase](https://github.com/GDelvoye/xp-staircase): Python/Angular application for a cognitive psychology face-recognition experiment, with backend tests and pre-commit tooling.

## Technical Focus

- Backend development with Django, Flask, Python, and PostgreSQL.
- Data modeling, custom query systems, and probability/statistical calculations.
- Docker-based local and production deployments.
- Small, maintainable tools designed around real use cases.
